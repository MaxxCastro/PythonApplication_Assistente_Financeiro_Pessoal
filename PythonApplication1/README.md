# Assistente Financeiro Pessoal

Aplicativo Streamlit simples para controlar gastos, receitas e metas.

Como executar:

1. Crie e ative um ambiente virtual (recomendado).
2. Instale dependências: pip install streamlit pandas sqlalchemy matplotlib
3. Execute: streamlit run PythonApplication1/streamlit_app.py

O banco SQLite será criado em PythonApplication1/dados.db ao abrir o app.
